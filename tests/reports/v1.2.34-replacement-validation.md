CE profile 使用等面加权及观测到的平方长度 `0.0001` 法线稀疏门限；native 继续按面积加权。两者重建组合姿态后扣除基础和较低阶的法线贡献。未重算时保留作者法线导入行为。参考为 CE **0.3.0 Preview**，SHA-256 为 `bc5cbbcb1444d539d35a36afdc7a84b7419839fd1b15674e2d0ec6ffc37e0758`；八类冻结参考存于 `tests/fixtures/ce-combined-normals.json`。这不等于任意复杂 rig 或游戏光照全面一致。

AG2 与反编译器在生成前取得同目标进程锁、恢复先前日志并记录输出指纹。未提交的中断恢复旧集，已提交的中断保留新集。目标或备份被外部改写时拒绝覆盖并保留恢复证据；用户可保留 `.newpage-output-transactions`、`.newpage-output-locks` 与备份后重跑同一任务。反编译器以每个模型目录为提交单位。持久化与已测进程终止恢复不代表任意硬件断电保证，也不向外部读者提供整套结果的原子快照。

VMD `-compile` 直接启动随包 **NewPageMergeMDL**，保留真实 `-game` 并以 `-OutDir` 暂存编译产物。参数检查包含中文、空格、`&`、`%PATH%`、引号和末尾反斜线；集成测试既有故障/参数探针，也有真实主编译器生成 IDST 模型的成功案例。VMD/L4D 使用整批普通错误回滚，尚无持久强杀恢复或同目标并发保护。Windows 反编译器及四个子工具的 MinGW 版本资源显式嵌入 UTF-8 manifest，中文路径集成检查通过。

后续 L4D 负例确认：存在的 Light MDL 若声明正序列数量但表偏移越界，旧构建会退出 0 并替换已有输出。修复后对表、数量及标签做结构预检，三类损坏均失败并保留全批旧结果，合法零序列仍可跳过。旧构建的 `-all` 还会用 Nick 的动作覆盖 Rochelle 的同名输出；retarget 文件名现同时包含 rig 与 target（`_for_<target>`）。独立回归将人物与 Light 的批处理路径及内容逐一对比各自单独运行，1/1 通过。补修后的 L4D 散列为 `57e42f752d47be1372ace38690bd043808e0c09238f797f1d579191452ad25a0`。

C4D 纹理标签按文档顺序应用，后一个适用标签覆盖前一个；命名多边形选择集限定作用范围，缺失选择集忽略，未覆盖面使用默认材质。材质拆分保留 UV 与作者法线，自动平滑在拆分前计算。范围限可编辑多边形；不包括程序化缓存、蒙皮、动画、模拟或着色网络烘焙。

Plum 原用户目录当前已不存在，因此使用留存副本并先核对全部 131 份文件与登记的原始 SHA-256；使用正确 GMod `gameinfo.txt` 与隔离输出。编译后输入及 gameinfo 不变，五份 MDL/VVD/VTX/PHY 与安装版及历史 v1.2.33 逐字节一致，保持 131 骨、572,277 顶点、21 个物理体。该生产编译没有额外游戏运行测试。

## CS2 完整模型与运行边界

从已安装 CS2 build 25966348 的官方 `ctm_sas` 资源提取了五个网格 DMX，制作了未经过 AG2 的 `sas_plain.vmdl` 对照和 1.1 倍缩放的 `sas_scaled.vmdl`。最终 AG2 生成的比例 clip/graph 与两个 VMDL 均由实际 ResourceCompiler 报告 `1 compiled, 0 failed`；scaled clip 的 75 条平移轨道中 61 条非零，未丢失原骨骼，新增 `camera`、`attachFoot_L`、`attachFoot_R` 三个辅助骨骼。完整数值和散列见 `ag2-full-validation-20261018/sas-scaled-validation.md`。

在 `-tools -addon npmdl_validation_20261018` 中，`resource_list` 确认 plain/scaled 模型及 `proportions_worldmodel`、`proportions_uimodel` 图已注册，未出现零售模式的 missing-manifest 警告。普通零售模式不能挂载这个 loose addon，因为官方 `gameinfo.gi` 启用了 `RestrictFlatFileAddonsToTools`；独立地图编译也因 ResourceCompiler 未挂载官方 core/csgo pak 而停止，未修改原游戏配置。

玩家 `SetModel` 后，plain 对照和 scaled AG2 模型都没有稳定显示为玩家实体；因此不能把结果归因于 AG2，也不能宣称重载、蹲伏、第一人称手臂、武器附件或游戏动作通过。只读 PE/RTTI 证据确认新建 `CCSPlayerPawn` 默认选择名为 `worldmodel` 的 AnimGraph2，但尚未证明本次 `SetModel` 调用重新绑定了生成 wrapper。运行日志和静态调查保存在 `C:/Users/Kud/Desktop/CODEMDL/.diagnostics/ag2-full-validation-20261018/`。
