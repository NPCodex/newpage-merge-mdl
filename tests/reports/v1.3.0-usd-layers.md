# v1.3.0 静态 USD 子层验证

验证日期：2026-10-25。本文记录本地 Windows/MSVC Release 编译器验证，正式包和其他平台检查以发布流水线为准。受测本地编译器 SHA256：`da5cd1c45eaaab885e370146cac58559ecbf5d0a1fdbad2d486ab8cf9ac38131`。

## 行为

普通文件新增静态 `subLayers` 组合。根层优先，子层按作者顺序递归参与；同路径 prim 及后代合并，强层默认属性、几何点、变换和激活状态覆盖弱层，空属性声明保留弱层默认值。显式 reference 可替换弱层 reference，外部路径保留作者层目录，内部 reference 查找最终层栈。根层舞台元数据不从子层继承。

有界子集及明确拒绝项见 [场景导入范围](../../SCENE_IMPORT.md#usd-组合的明确范围)。子层时间偏移在 USDA 输入中由底层解析器提前拒绝；组合器也检查二进制层中的非单位偏移。两个层同时提供 API schema 列表时明确拒绝，不静默丢弃弱层列表。没有把复杂层列表操作、动画层、variant 层或骨架层解释为静态完整支持。

独立 USDC 样本还发现并修复了底层 Crate 读取器将空 `TokenVector` 的零字节读取误判为失败的问题。只声明子层、不含本地 prim 的二进制根层现在可以加载。

## 验证结果

- USD 相关 17 项通过，包含在完整 467 项兼容回归通过记录中。其中新增 6 项覆盖根层/第一子层/后续子层强度、嵌套相对路径、后代覆盖、空属性声明、`active=false`、依赖记录、内部引用最终层栈、显式外部引用替换、`resetXformStack`、根层 `defaultPrim` 隔离、只含子层的 USDC 根层，以及缺层/循环/复杂内容失败时保留旧输出。原有单引用、实例和选定 variant 测试仍通过。
- `tests/usd_reference_validation.py` 使用独立 OpenUSD 26.8：17 组 × 3 种输入全部匹配，共 51 组比较。每组比较作者 USDA、保留组合的 USDC、OpenUSD Flatten 后 USDC 与 `UsdGeom.XformCache` 加实例代理遍历所得世界顶点多重集合，四舍五入到小数点后 5 位。
- 新增子层部分占独立参考中的 4 组：嵌套层覆盖和激活状态、相对资源/内部引用、显式引用替换/重置变换、无本地 prim 的根层。其余 13 组重新核对既有引用和 variant 行为，覆盖路径归一化对旧功能的影响。

独立参考结果保存在 [v1.3.0-usd-oracle.json](v1.3.0-usd-oracle.json)。测试使用项目自行生成的三角形和场景，不包含用户模型、游戏素材或参考软件二进制。

## 复现与边界

```text
python tests/compatibility.py <compiler> -k usd -v
python tests/usd_reference_validation.py <compiler> <evidence-directory> --usd-module-path <usd-core-directory>
```

普通回归不依赖 OpenUSD；独立参考需要 `usd-core==26.8`。这次比较确认的是固定样本的世界顶点集合，并未认证完整拓扑顺序、材质网络、法线、动画、骨架或游戏渲染等价性。USDZ/内存输入仍须预先展开组合。
