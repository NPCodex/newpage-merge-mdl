# v1.3.0 碰撞焊接与分组

2026-10-25，真实编译输出确认并修复了容差链丢失部分碰撞几何的问题。
位置容差链、法线容差链和多骨骼碰撞路径均有旧版失败、新版通过的输出回归。
本报告的程序是本地 MSVC Release 构建；正式发行包验证由发布报告另行记录。

## 可复现缺陷

`BuildVertWeldTable` 原先保存首个匹配的前驱索引，但该前驱可能已经焊接到另一个顶点。
岛分组仅查询一次索引，并把已焊接顶点初始化成 `-1`，使连接到容差链末端的新增几何
被错误地标记为不存在。只测试完全重复几何，或只测试一个最终触发全几何回退的物体，
会掩盖这个问题。

自制闭合盒体复现覆盖三个具体结果：

- 位置为 `0 → 0.75 → 1.5`、`$weldposition 1` 的链，连接较大的第三个盒体；
  另放一个远处独立盒体防止回退掩盖丢失。旧版第一个碰撞岛的 X 范围只有 `0..10`，
  新版为 `0..21.5`。与独立手工消除中间重复盒体、直接焊接到首个顶点的输入相比，
  解码后的凸包顶点和体积一致。
- 同位置、法线分别转动 `0°、20°、40°`，`$weldnormal .9` 的链：
  旧版仅保留约 `2000 in³`，新版保留预期的 `9000 in³`。
- 同类位置链放入 `$collisionjoints`，另一个骨骼承载远处盒体；旧版仍丢失扩展部分，
  新版保留 `21.5` 的 X 上界，另一个骨骼的几何保持独立。

## 实现与兼容边界

仍采用源顶点顺序中的**首个**合格前驱，保持原有浮点距离 `<=` 与法线点积 `>` 判断；
现在将前驱解析成最终代表顶点。没有改为最近点，也没有把所有相邻点无条件合并。
跨空间网格单元的多个候选仍按原始索引选取首个匹配。

空间网格只筛选候选，使用保守单元宽度；极端坐标/容差比例或非有限容差退回原有扫描。
默认零位置容差也可以使用网格。连接分量用带路径压缩和按秩合并的并查集代替反复
全网格传播，按原有源顶点顺序输出凸包与顶点。多骨骼路径在本次碰撞构建内复用同一
源网格的焊接表，不跨编译或跨已变换源数据复用。

这减少普通分散网格的候选比较及多骨骼重复计算；极密集候选、极端坐标回退仍可能
达到二次复杂度，不宣称任意网格均为线性耗时。没有新增通用凹体分解或改变 VHACD。

## 验证

`tests/physics_extra_cases.py` 新增 5 项输出级回归，包括上述三个缺陷，以及跨单元
首匹配顺序、零位置容差、恰好等于位置容差、法线严格大于边界。
旧版为 3 项失败、2 项通过；新版 5 项全部通过。
新构建的 `compatibility.py -k collision` 共 17 项全部通过。

`tests/physics_benchmark.py` 提供四个独立自制样本：默认单盒体、1024 个分离盒体、
1024 个使用正位置容差的分离盒体，以及 64 骨骼各 8 个盒体。每个程序每个样本
1 次预热、5 次测量，顺序交替；比较实际输出的所有刚体、凸包、体积、范围及排除
MDL 校验和字段后的 PHY 字节。两版所有运行输出均一致，共 48 次编译成功。

正式本地对照在其他本机构建与测试暂停的窗口执行；仍不宣称操作系统完全无后台负载。
下表为本地同配置程序的有界测量，不是任意模型或最终发行包的普遍提速结论：

| 样本 | 旧版碰撞阶段中位 ms | 新版碰撞阶段中位 ms |
| --- | ---: | ---: |
| 默认单盒体 | 0.1489 | 0.1681 |
| 1024 分离盒体，零位置容差 | 66.6136 | 39.4347 |
| 1024 分离盒体，位置容差 0.25 | 67.6693 | 39.8299 |
| 64 骨骼 × 8 盒体 | 520.4010 | 27.6287 |

两个大单刚体样本碰撞阶段降低约 41%，多骨骼样本降低约 95%；默认单盒体增加
0.0192 ms。完整进程中位耗时分别为 `85.12→89.80`、`177.55→147.03`、
`177.16→154.80`、`622.78→125.23` ms；最小样本波动约 +5.5%。
没有把微小样本的相对百分比隐藏为零，四个样本的峰值工作集均无实质增长。

两程序来自同一本地 MSVC x64 Release 配置：`/O2 /Ob2 /DNDEBUG`、动态 CRT、IPO 关闭。
