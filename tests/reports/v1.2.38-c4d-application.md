## Saved caches

The scene has a translated/rotated parent and two cube generators. Each contains
56 quads; the second is evaluated through a bend deformer. The bridge outputs two
meshes and 224 triangles, with no duplicated control/source geometry. The four
original named nodes retain their parent relationships and local transforms;
extra cache nodes are structural wrappers.

positions, UVs, corner normals, material names, local hierarchy and transformed

## Skeletal assessment and failure behavior

The second scene contains a six-point strip, two joints, weights 0/0.5/1 and a
linear rotation track sampled at frames 0, 15 and 30 at 30 fps. Comparing the
authored linear blend model with the application's evaluated points gives maximum
error 0.000118842 cm, below the explicit 0.0002 cm assessment tolerance. The
comparison uses the authored weight contract and recorded joint matrices; it does
not extract weights through Cineware and does not prove a skeletal importer.

The real animated skin document returns an explicit unsupported-animation error,
creates no GLB and preserves a previously compiled MDL family. Separate
SDK-authored fixtures test static skin rejection and animation rejection. Live
skeletal C4D import remains unsupported; exported bind matrices, split-corner
weights and evaluation dependencies must be specified before implementing it.

All **13 C4D regression groups pass** with the candidate helper, including static
geometry/materials, invalid input, Unicode paths, node selection, failure cleanup,
the real saved caches and real animated-skin rejection. This does not certify all
generators, plugins, C4D versions, arbitrary rigs, constraints or animation layers.
