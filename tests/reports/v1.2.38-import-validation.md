## 独立参考促成的修正

OpenUSD 对照发现并修正了单靠自制预期没有覆盖的问题：`resetXformStack` 被误当相对父节点；实例错误接受直接本地子节点；继承的 instanceable/显式 false 意见未传播；本地重新激活引用根失效；扩展同名变体时引用层误取默认选项；USDC Layer 读取丢失 def/over/class specifier。OpenUSD 展平的未定义原型现在仅作为引用来源，不重复导出。

需要上下文组合的同名引用子节点覆盖，以及本地与变体贡献多个引用的情况，本轮采用明确失败。回归验证这些请求不会成功生成部分几何，也不会替换旧模型。这不是对该功能的完整支持。

## 复现入口

普通测试不依赖 OpenUSD。运行 `tests/compatibility.py <compiler>` 时，本文测试随现有 Compatibility 类发现；测试实现位于 `tests/compiler_input_cases.py` 和 `tests/extended_cases.py`。VPK 独立 helper 使用 `tests/content_mounts.py`，Lua 使用 `tests/runtime_metadata_test.py`。

可选的独立参考需要已安装 `usd-core==26.8` 的 Python：

```text
python tests/usd_reference_validation.py <compiler> <evidence-directory>
```

它保存作者样本、OpenUSD 导出的 USDA/USDC 和逐组 `results.json`。非默认安装可传 `--usd-module-path <directory>`。固定 Crate 回归的文字源、二进制与生成说明在 `tests/fixtures/usd/`，没有游戏或第三方人物数据。

## 验收边界

- 缓存预算针对保留 aiScene 的估算容量，不是进程 RSS 硬限制；不同采样率仍各自保留解析结果。本轮完成预算、观测与生命周期管理，没有声称拆分几何/采样缓存或测得加速倍数。
- 烘焙误差针对均匀参考样本。它不覆盖任意连续时刻、最终 MDL 量化和游戏渲染；STEP 及无法确认插值的导入器保守保留全部参考帧。
- USD 仅支持 [场景导入说明](../../SCENE_IMPORT.md) 列出的有界静态子集。独立参考核对的是世界顶点集合，不是完整材质、拓扑顺序、动画、骨架、法线或着色器等价性。
- 上述首轮使用自行编写的合法样本及 OpenUSD 导出。以下补充真实 Blender 制作/导出；仍无本轮 USD 游戏运行证据，不能推导全部 DCC/游戏兼容。

## 2026-10-21：真实 Blender 导出补验

使用本机 Blender **5.4.0 Alpha**（`45e7704f386b`，应用构建于 2026-10-20），

`tests/blender_usd_validation.py`。脚本新建独立 `.blend`：两个嵌套父节点，
