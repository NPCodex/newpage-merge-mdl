# 自制非标准人形：Blender 到 VMD 重定向验证

2026-10-21 使用真实 Blender **5.4.0 Alpha**（`45e7704f386b`）后台新建、保存并导出
一个有蒙皮网格的人形下肢测试模型。实际应用生成 `.blend` 与 GLB，再由当前编译器
生成 MDL，最后由 `vmd2valvebiped -mapping` 生成四组 DMX。全部输入由脚本创作，
没有使用或修改用户人物资源。结果与工具/输入 SHA256 见
[机器记录](v1.2.38-blender-vmd.json)。

## 样本和独立参考

八根作者骨使用含空格的非 ValveBiped 名称：髋、头、左右大腿/膝/踝；左右两条腿
长度和弯曲量不同，骨局部 roll 分别为 `0.13 × (编号+1)` 弧度。每根骨对应一个
实际顶点组与 Armature modifier，64 个作者顶点经法线拆分成为 192 个 VVD 顶点。
编译器另保留一个 GLB 场景根，共九根骨。

绑定参考来自 Blender 求值后的网格与作者骨坐标。检查每个 VVD 顶点的位置及其
活动权重对应的作者骨名；再独立读取 MDL 逆绑定矩阵与 DMX 位置/四元数轨道，
按父子矩阵重建 31 帧世界姿态。根移动和脚目标直接由作者输入公式预测；FK 使用
MMD 到目标坐标的反射推导 X 轴 `-0.4` 弧度旋转，并独立计算网格顶点的位置。
不调用转换器的 IK/FK 求解实现作为参考。

四组输入为：零动作绑定、双脚固定且骨盆移动、仅左脚侧移、左腿 FK 旋转。
`upright keep`、明确的左右/向上轴与版本化角色映射避免自动站立影响对照。

## 结果

| 检查 | 最大误差或观测 |
| --- | --- |
| 编译后绑定关节 / 网格位置 | `1.55e-5` / `3.98e-6` 模型单位 |
| VVD 蒙皮骨名和单骨权重 | 192 个全部正确，错误绑定 0 |
| 零动作重定向关节位置 | `2.66e-5` 模型单位 |
| 双脚固定、骨盆位移约 1.148 单位时的脚漂移 | `3.58e-5` 模型单位 |
| 根轨迹 / 左脚目标轨迹与输入公式 | `1.21e-4` / `4.82e-5` 模型单位 |
| 左脚侧移约 0.711 单位时的右脚漂移 | `2.66e-5` 模型单位 |
| FK 左脚位移 / 右脚漂移 | 约 13.510 / `2.47e-5` 模型单位 |
| FK 世界旋转 / 蒙皮网格独立旋转参考 | 浮点角误差报告 0 度 / `3.56e-5` 模型单位 |
| 全部动作的腿段长度变化 | `1.77e-5` 模型单位 |
| 膝盖弯曲方向 | 全部保持作者前侧；最小前向偏移约 3 单位 |

所有位置检查使用预定 `0.001` 模型单位容限，旋转容限 `0.01` 度。轨道采样包含
DMX 时间量化和插值，因此不把浮点结果写成精确数学等价。此样本没有发现需要修改
映射/IK 实现的新缺陷。

## 复现与边界

```text
python tests/blender_vmd_validation.py COMPILER VMD_TOOL BLENDER NEW_OUTPUT_DIRECTORY
```

最终原始证据位于本机 `.diagnostics/blender-vmd-v1238-final/`：真实应用项目、GLB、
编译结果、四组 VMD/profile/DMX、JSON 与日志。Blender 是可选验收工具，不是用户
运行转换器的依赖。

这补齐了真实 DCC 创作的非标准命名、非对称比例、绑定方向、脚固定与数值蒙皮
对照；样本是八骨下肢模型，没有手臂/手指、多骨混合权重、扭转辅助骨、约束或游戏
运行。它不能代表生产人物的视觉质量、完整动作覆盖或任意骨架支持。
