This records exact intermediate snapshots. It does not assert that a later
integrated candidate, changed C4D helper or Release has already passed. Machine

## Linux packages

[Run 39751372432](https://github.com/NPCodex/newpage-merge-mdl/actions/runs/39751372432)
at `4e00894` passed both GCC 13 and Clang 18 jobs on Ubuntu 24.04 LTS x86_64.
Each built all seven native tools as MinSizeRel without IPO, then ran recovery and
format CTest, actual packaged helper/decompiler/subtool/input suites, **445
compatibility tests**, and native runtime checks after unpacking the complete ZIP.

The seven ELF tools retain executable permissions, resolve their loaders and
dynamic dependencies and pass usage/version probes. Maximum observed required
versions are GLIBC 2.38, GLIBCXX 3.4.30 and CXXABI 1.3.13, below the declared
Ubuntu 24.04 contract ceilings 2.39/3.4.32/1.3.15. This validates Ubuntu 24.04;
it does not certify an older distribution merely because some symbol requirements
are lower.

The first attempted run exposed a real package layout error: extensionless Linux
`subtools/ag2proportions` collided with `subtools/ag2proportions/README.md`.
Guides now use flat filenames alongside executables, packaged Markdown links are
updated, and verification rejects file/directory conflicts before extraction.
The corrected archive layout also passes the local 51-test automation suite.

## Two clean builds and symbols

The same run built one immutable source ZIP twice in distinct source/build paths,
using MinSizeRel, IPO enabled, reproducible paths and separate symbols:

| Platform | Executables | Complete runtime ZIP | Complete symbol ZIP |
| --- | --- | --- | --- |
| Ubuntu 24.04 / GCC 13 | 7/7 byte-identical | 153 members and ZIP bytes identical | 8 members and ZIP bytes identical |
| Windows 2025 / MSVC | 8/8 byte-identical | 155 members and ZIP bytes identical | PDB bytes differ; matching native identities verified |

Source ZIP SHA256:
`c3d47a361887f1feb4a5a02d6ac54e40ef76223650f6e97631708b58f3203746`.
Windows includes the same externally pinned old C4D helper in both archives; it
is an identical input, not a fresh SDK build or new-helper acceptance claim.

Linux originally differed because LTO's generated debug compilation unit did not
receive the compile-stage path maps. Applying the same maps at link time restored
byte equality for ELF files, separate debug data and both complete archives.

Windows PDBs retain absolute linker object/CVTRES paths. Their bytes are compared
and reported, but equality is not claimed. Both archives must still match each
executable's PDB GUID/age and exact source provenance. Linux matching additionally
checks build ID, debuglink filename/CRC and real debug-info/line sections.

and line; compiler `main` resolves to `src/mdlcompiler/main.cpp:700`, decompiler
`main` to `src/mdldecompiler/main.cpp:3516`, and the other five entry points are
listed in the JSON report. A Draco dependency function resolves to
`src/libs/assimp/contrib/draco/src/draco/compression/decode.cc:87`.

That local snapshot's exact source archive is identified by SHA256
`2cab60d51222695974a72dd0a7ce7e263c4e1431d5936f2260cf1c6495986eee`.
It was an uncommitted candidate, so its entry-point line numbers are historical
evidence rather than an assertion about current HEAD. An additional authored
probe resolves to `src/probe.c:6`. These results do not guarantee recovery of
every optimized/inlined stack frame or prove that a particular crash was tested.

## Bounded mutations

The ordinary Windows run completed 240 authored mutations: 69 accepted, 171
rejected, no crashes, timeouts or RSS/log-budget overruns. It did not enable
sanitizers and cannot substitute for the Linux check.

The first actual Clang ASan+UBSan run found a signed-left-shift bug while compiling
the valid seed model in `writemdl.cpp:3164`, before any mutations ran. Commit
`641b7e3` uses defined unsigned wrapping arithmetic while preserving bit-27
feedback and every iteration's checksum header writeback.

[Run 39752234113](https://github.com/NPCodex/newpage-merge-mdl/actions/runs/39752234113)
tests that fix with address/undefined/leak detection enabled, 240 requested
samples and a 180-second mutation/reduction budget. **It is still in progress**;
no successful sanitizer mutation total is claimed yet. Any later result must
update this report and retain failures/minimized inputs. This is a bounded
experiment, not proof that arbitrary model files are safe.
