# v1.3.0 report, batch and diagnostic validation

2026-10-25, Windows x64, local MSVC Release builds using the same CMake cache,
toolchain and flags. The baseline is v1.2.39; the candidate is the v1.3.0
development binary identified below. These are not the final MinSizeRel/IPO
release binaries. Measurements ran with project builds and game tests paused;
the operating system was not stripped of all background activity.

Report output now holds serialized text in memory until a complete durable
transaction intent exists, then stages it directly. It avoids the former scratch
workspace and repeated disk copies. Locking, fingerprints, recovery, backups and
commit semantics remain. All 17 persistent-output recovery tests passed,
including actual process termination at report transaction phases; 10 actual
compiler report/diagnostic tests passed. No arbitrary power-loss guarantee follows.

## Measured process wall time

Each self-authored fixture/mode/binary used one separately recorded first
process, one warmup and seven measured processes. The existing benchmark
harness verified input identities, per-run model determinism and matching
toolchain/build configuration. These are medians in milliseconds:

| Fixture | v1.2.39 plain | v1.3.0 plain | v1.2.39 perfjson | v1.3.0 perfjson |
| --- | ---: | ---: | ---: | ---: |
| small | 82.60 | 76.80 | 100.41 | 97.12 |
| large-grid | 147.75 | 144.44 | 176.28 | 166.51 |
| clips-morphs | 95.47 | 95.83 | 119.04 | 128.28 |

The report path still costs additional time. Two instrumented samples improved
modestly and the clips/morphs sample became slower; these measurements do not
establish a general report performance gain. Peak working sets remained within
the harness's 15% regression gate. The separate collision optimization has its
own output-equivalence and timing evidence in [collision report](v1.3.0-collision.md).

## Controlled batch concurrency

All 13 incremental-helper tests passed against the final local candidate. The overlap
barrier test proves two native compiler jobs actually run concurrently and
compares their outputs with sequential execution. Other checks cover cache
reuse, per-job failure isolation, previous-output preservation, budget-limited
serial execution and rejection of incomplete/overlapping input roots. A real
symlink/junction into another job's output is rejected before workers or cache
creation, even when the declared parent root appears independent.

`--jobs` defaults to 1 (range 1–64). An optional memory budget divided by the
per-job estimate limits scheduling, not the operating system RSS. Plans must
declare complete input search roots and independent outputs; arbitrary engine
dependency coverage cannot be proved by the wrapper. Results retain plan order.
This is tested concurrency, not a universal throughput or memory-use claim.

## Actionable diagnostics

An invalid SMD numeric field produces NP1101 with the exact mesh line in
`related_locations` while retaining the QC include callsite. A missing filename
containing digits does not fabricate a source line. Optional `hint` explains
recognized source, resource mount, output alias and recovery failures.
