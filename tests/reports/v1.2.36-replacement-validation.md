## Linux 与发布包证据

本轮发布流程要求 Windows MSVC、Linux GCC 的正式包，以及 Linux Clang 无 LTO 验证包全部通过完整包内回归。Clang 流程另注入不支持 LTO 的编译器包装器，确认 CMake 自动关闭 IPO。Linux 解压后的七个 ELF 工具检查 x86-64/小端、加载器、动态依赖、ZIP 执行权限、usage 输出及支持的 help/version 参数。

LTO 检测已按 C/C++ 分别执行，避免 C 成功掩盖 C++ 失败。本地最小正反例实测：拒绝 LTO 时自动 OFF、正常工具链保持 ON，两者编译和运行均成功。

这些是本轮发布门禁，不将旧 Linux 运行 `39202315457` 当作新 smoke 测试证据。实际 CI 结果与下载附件对应的工作流链接记录在 [v1.2.36 Release](https://github.com/NPCodex/newpage-merge-mdl/releases/tag/v1.2.36)；最终附件 ID/大小/digest 由 GitHub API 与构建归档复核，标签不移动。手动替换与自动检查共用源码 fingerprint，未变化的下一次检查不会另造版本。
