# Cinema 4D import validation

Updated 2026-10-21 for the v1.2.38 candidate. This records item 15's separate
implementation and validation stages; a successful SDK build is not an application
comparison.

| Stage | Current evidence | Remaining acceptance |
| --- | --- | --- |
| Editable static polygons | Cineware 22 bridge builds with MSVC 14.44. Eleven black-box regression groups pass, including translated hierarchy, material selections, UVs, authored/generated normals, compiled MDL/VVD geometry and five new rejection cases. | Recheck with the final packaged helper. |
| Saved generator/deformer caches | Source follows the public SDK cache precedence and traverses nested/sibling caches. Inherited texture tags, control-object suppression, depth/node bounds and cycle checks are implemented. A genuine SDK-authored cube without a cache is explicitly rejected. | Execute `author_fixtures.py` in activated Cinema 4D, then compare transformed geometry, hierarchy, normals, UVs and materials with its Current State to Object reference. Check absence of duplicated source geometry. Verify Cineware 22 can read the Cinema 4D 2026 save. |
| Skeleton and animation assessment | Public SDK exposes joint links, weights, geometry/joint bind matrices and curve evaluation. The current bridge explicitly rejects skin weights and animation tracks. A self-authored SDK document verifies each rejection without replacing an existing model. | Obtain the real application skin/animation fixture and compare bind matrices, split-corner weight mapping and sampled poses before implementing a supported subset. |

The Cinema 4D 2026 application is installed on the development computer, but its
license manager requests Maxon App sign-in. No real application fixture or cache
comparison has yet run. No SDK private cache setters or binary surgery are used
to fabricate successful cache coverage.

The skeletal assessment identifies concrete additional requirements:

- Split polygon corners must retain point-to-joint weights. A deformed cache
  cannot be substituted for bind geometry when exporting a live skeleton.
- Joint inverse bind matrices must include the geometry bind matrix and agree
  with the importer hierarchy and centimeter/handedness conversion.
- Curve values alone do not establish parity for constraints, expressions,
  animation layers, arbitrary plugins or simulation. A supported animation
  subset needs sampled application reference poses and explicit rejection of
  unsupported evaluation dependencies.

The candidate helper is built outside the repository. The currently pinned
`v1.2.34` external helper is not this candidate; final packaging must stage the
matching rebuilt helper and verify its identity. Proprietary SDK headers,
libraries, application binaries and vendor samples are excluded from source and
package changes. All checked-in C4D fixtures are generated by this project's
`fixture.cpp`, using public SDK allocation and save APIs.
