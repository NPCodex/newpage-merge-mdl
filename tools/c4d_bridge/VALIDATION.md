# Cinema 4D import validation

Updated 2026-10-22 for the v1.2.38 candidate. This records item 15's separate
implementation and validation stages; a successful SDK build is not an application
comparison.

| Stage | Current evidence | Remaining acceptance |
| --- | --- | --- |
| Editable static polygons | Cineware 22 bridge builds with MSVC 14.44. Thirteen black-box regression groups pass, including translated hierarchy, material selections, UVs, authored/generated normals, compiled MDL/VVD geometry, five SDK-authored rejection cases and two real application cases. | Recheck with the final packaged helper. |
| Saved generator/deformer caches | Cinema 4D 2027 authored and saved two cube generators, including a bend deformer. Cineware 22 reads both. Compared with application Current State to Object: four source hierarchy nodes, 224 triangles, materials, UVs, normals and world transforms agree within float tolerances; no duplicate source geometry. See the [application report](../../tests/reports/v1.2.38-c4d-application.md). | This proves the two authored 2027 fixtures, not all generators, versions or plugins. The 2026 application was not used to author the validated files. |
| Skeleton and animation assessment | The real 2027 two-joint, six-point animated strip is explicitly rejected without GLB output or replacing an existing MDL. Its three evaluated poses agree with the authored linear blend model within 0.000119 cm. Independent SDK fixtures separately cover animation and skin rejection. | Live skeletal import is not implemented. A supported subset still requires exported bind matrices/weights, split-corner mapping and broader constraint/layer evaluation contracts. |

The reference files were generated by licensed Cinema 4D 2027 (`2027000`) using
`author_fixtures.py`. They are self-authored project assets, not vendor examples.
The application was subsequently removed by the user; the committed C4D files
and application JSON remain sufficient to rerun bridge comparisons without an
application installation. No SDK private cache setters or binary surgery are used.

The skeletal assessment identifies concrete additional requirements:

- Split polygon corners must retain point-to-joint weights. A deformed cache
  cannot be substituted for bind geometry when exporting a live skeleton.
- Joint inverse bind matrices must include the geometry bind matrix and agree
  with the importer hierarchy and centimeter/handedness conversion.
- Curve values alone do not establish parity for constraints, expressions,
  animation layers, arbitrary plugins or simulation. A supported animation
  subset needs sampled application reference poses and explicit rejection of
  unsupported evaluation dependencies.

The candidate helper is built outside the repository. The currently pinned
`v1.2.34` external helper is not this candidate; final packaging must stage the
matching rebuilt helper and verify its identity. Proprietary SDK headers,
libraries, application binaries and vendor samples are excluded from source and
package changes. Checked-in C4D fixtures are generated by this project's
`fixture.cpp` (public SDK APIs) or `author_fixtures.py` (licensed application APIs).
