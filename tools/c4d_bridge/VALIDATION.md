# Cinema 4D import validation

Updated 2026-10-25 for v1.3.0. The bridge supports the bounded rig contract in
[README.md](README.md); the earlier v1.2.38 skeletal *assessment* is historical.

| Stage | Current evidence | Limits |
| --- | --- | --- |
| Editable static polygons | Windows Cineware 22/MSVC helper passes translated hierarchy, material selections, colors, UVs, authored/generated normals and compiled MDL/VVD checks. | Source materials/shader rendering must be supplied separately. |
| Saved generator/deformer caches | The preserved Cinema 4D 2027 application reference still matches: four source nodes, 224 triangles, materials, UVs, normals and world transforms; no duplicate source geometry. | Only the two authored generator/deformer cases, not arbitrary plugins. |
| Joints, weights and linear animation | The actual 2027 two-joint document is now imported. GLB joint links, inverse binds and point weights drive an independent GLB evaluator; positions at frames 0/15/30 agree with saved application results within 0.000122 cm. Joint world matrix component error is below 2.24e-8. | The licensed application is absent. This reruns comparison against its preserved output, not a new application session or arbitrary-rig conformance. |
| Split corners and transformed binds | A separate SDK-authored two-material strip has nonidentity mesh/joint binds and a shared-position UV seam. Eight exported vertices retain their weights/UVs; sampled translation, HPB rotation and nonuniform scale match independent analytical poses at 0/15/30. | One weighted mesh with the documented linear Skin settings; complex rigs are rejected. |
| Compiler integration | The application rig produces both named joints, six VVD vertices, two 50/50 blended points and a 31-frame 30 fps skeletal clip. Animated scale explicitly requires BakeSceneAnimation; the accepted baked path produces 31 timestamped frames. | The Source runtime vertex-animation consumer still must be configured for the baked workflow. |
| Rejection and recovery | Missing skin, spline tracks, bad weights, dual-quaternion skin, constraint tags, duplicate names, muted tracks and invalid bind matrices fail without GLB output and preserve previous MDL files. | Constraints, layers, takes, nonlinear/time-remapped tracks, multi-mesh skins and simulation are not evaluated. |

The real reference files were generated by licensed Cinema 4D 2027 (2027000)
on 2026-10-22 using author_fixtures.py. The application was subsequently removed
by the user. The committed .c4d and application JSON files suffice to repeat
the independent comparisons. No proprietary application binaries, SDK headers,
libraries, examples or private cache setters are committed or packaged.

The importer reads bind geometry instead of the saved deformed cache, applies
the geometry matrix in each joint inverse bind, and retains source-point weights
through all corner/material splits. Cineware 22's sparse indexed accessor repeats
an entry for the preserved 2027 file; the point-addressed accessor is used instead.
Its quantized values (authored 0.5 can read as 0.500008) are normalized only after
checking the narrow sum tolerance.

The helper is built and tested separately from the main compiler. The release
must update automation/windows-extras.json, verify the exact archive/executable
hashes, and rerun tests/c4d_bridge_test.py with the packaged helper. Build/test
identity and any final package results belong in the
[v1.3.0 C4D report](../../tests/reports/v1.3.0-c4d.md).
